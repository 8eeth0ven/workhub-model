# 产业图谱

把算力、汽车、能源等产业的实体、作用、产地和关联放在一处，逐条保留来源、时间与变更，再用具体问题检查资料遗漏。

这是一个有证据的研究工作台。产业从导入数据自动生成；同一实体可跨多个产业。默认 Codex 明亮，使用 Workhub 的十套配色，支持中英文切换。页面只保留搜索、产业筛选、实体／关系与可展开设置，不用大标题占据内容空间。

## 开始使用

需要 Python 3.10+，只用标准库。在模块目录执行：

```sh
python3 bin/build_data.py
```

没有资料时会显示“尚未导入产业事实”。要查看**全部为虚构内容**的离线演示：

```sh
python3 bin/build_data.py --demo
```

准备符合[数据格式](docs/guide.md)的资料后导入并生成网页：

```sh
python3 bin/import_data.py --input facts.json --output data/atlas.json
python3 bin/build_data.py --input data/atlas.json
```

打开 `site/index.html`。从模块仓库接入 Workhub 的命令：

```sh
python3 manage.py connect industry-atlas --installed ../my-industry-atlas --workhub ../workhub
```

连接只登记网站；需要手动准入的 Workhub 版本仍由用户添加到项目空间。安装和连接不会读取其他项目、聊天或会员资料，也不会采集或调用模型。

## 如何查看

- **实体**：先看名称、类型、一行作用；点选后查看结构化属性。总部、注册地、设计地、制造地、原料产地分开记录，缺失不按总部推断。
- **证据**：每条属性和关系都有声明状态、观察日期、有效期与来源。来源发布日和读取日分开，未知日期保持未知。
- **关系**：围绕选中实体渐进展开一跳，最多 24 个节点、36 条边。点节点查看该实体属性与变更，点边或关系列表查看原声明证据，完整列表可继续展开。图里省略已被变更记录标为替代的旧声明；历史关系留在列表。
- **变更**：新旧声明保留，通过变更 ID 连接。没有变更连接的冲突并存，不自动选一条当真。
- **追问**：围绕当前属性生成六类规则问题和验证动作，检查范围、口径、来源、反例、经济后果与时间边界。它不是模型评价，也不声称行业覆盖完整。

“来源披露”“已标多源核对”“推断”“假设”分别呈现。多源状态只要求至少两个已录入来源组，独立性和事实真伪仍需回到原始材料核对。关系存在不自动证明独家供应、因果或投资价值。

## 更新与使用模型

```sh
python3 bin/import_data.py --input update.json --output data/atlas.json --merge
python3 bin/build_data.py --input data/atlas.json
```

首次导入可不带 `--merge`；已有资料更新必须带 `--merge`，不带会替换整个快照。合并时保留稳定 ID；更正属性用新声明与变更连接，不覆盖旧声明。可以把[研究提示词](prompts/industry-research.md)交给自行选择的 CLI 或 API，要求有证据地整理资料，再人工检查后导入。模块本身不保存 Key、不自动调模型，也不替用户标记“已理解”。

真实资料与生成页面应留在本机。对外发布前检查项目名称、路径、个人信息、凭据和本地数据；源码包只包含空态、虚构演示与通用实现。
