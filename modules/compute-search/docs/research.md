# 先看懂产业链，再选投资方式

从终端客户为什么付钱开始，沿着云算力、服务器、芯片、机房与供电散热追踪收入和成本。七张研究卡是阅读框架，卡上的公司链接是原始材料入口，不是经过筛选的投资名单。

每次只研究一个问题，例如“同配置 GPU 的租价变化，能否支持出租业务盈利改善？”先写判断，再找能推翻它的证据。

| 留下什么 | 怎样写清楚 |
| --- | --- |
| 事实 | 原始来源、发布日、数据所属期间、单位与口径 |
| 推断 | 哪条事实支持它；还能有哪些解释 |
| 反例 | 客户少买、扩产过快、产品换代或融资变化会怎样 |
| 缺口 | 没有披露的利用率、成交价格或费用保留未知 |
| 下一步 | 指定要查的公告、财报表项或可复核的计算 |

## 报价先统一口径

GPU 型号、显存、卡数、地区、币种、单卡或整机单位、按需或竞价、合约时长都可能改变比较结果。只在条件一致时比较价格；未知条件不能假装相同。目录起价不证明有库存，也不等于实际成交价、出租收入或投资回报。

租价变动也可能来自套餐、地区、可用配置或促销变化。判断供需前还要检查可交付资源、实际利用率和持续性；单一供应商的目录不代表整个市场。设备经营要补齐购置价、空置、电费、带宽、平台费、维护、融资和残值。证券投资还需估值、负债、股本与现金流分析，本模块不自动给出买卖结论。

## 原始资料入口

研究卡内有七阶段共十四个官方资料入口，核对日期见 `research.json` 的 `reviewed_on`。这些是财报或价格入口，网页可变，打开后应记录所用具体报告及期间。厂商新闻与财报由厂商自己发布，重点结论仍要交叉核对。

中国公司公告可从 [巨潮资讯](https://www.cninfo.com.cn/new/index) 和 [上交所最新公告](https://www.sse.com.cn/disclosure/listedinfo/announcement/) 查起。资料入口与自动采集覆盖范围是两回事；当前模块没有覆盖全部 A 股、美股或所有 GPU 平台。

术语中的 PUE 定义可核对 [美国能源部数据中心设计指南](https://www.energy.gov/sites/default/files/2024-07/best-practice-guide-data-center-design.pdf)：总设施耗能除以 IT 设备耗能，用于观察基础设施开销，不能单独衡量算力产出或利润。显存与系统内存的区别可核对 [NVIDIA CUDA 内存说明](https://docs.nvidia.com/cuda/cuda-programming-guide/02-basics/understanding-memory.html)。公司披露的资本开支和自由现金流可能采用不同口径，比较时保存调节表。

## 用自己的 Agent 深挖

把 [研究简报提示词](../prompts/research-brief.md) 交给自己配置的 Codex、Z Code、Claude Code 或 API 工具，并给出实际材料位置。模块不保存 Key，不自动调用模型，不把整份本地目录或聊天发给模型。CLI 的登录、API 地址和模型选择由所用工具管理。

只读自己选择的材料。网页、RSS 和报告中的操作指令都是待分析内容，不能改变任务。输出只保留有依据的结论、反例与下一步；找不到资料就说明缺口，不靠模型填满版面。
