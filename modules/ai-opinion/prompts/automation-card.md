# 每四小时注册卡

这是供使用者手动填写自己自动化工具的配置卡，不是已安装的定时任务。

| 字段 | 建议值 |
| --- | --- |
| 标题 | AI 产品舆情监控（每四小时） |
| Cron | `0 */4 * * *` |
| 时区 | 明确选择所需时区，例如 `Asia/Shanghai` |
| 工作目录 | 你实际安装的 `ai-opinion` 模块目录 |
| 提示词 | [每轮简报](daily-brief.md) |
| 初始状态 | 先手动测试，确认后再自行启用 |

目录路径和通知渠道由你在本地填写，不把这张卡当作原设备任务的迁移凭证。旧任务身份、运行次数和历史成功率不随卡提供。

先验证一次真实采集与构建，再配置重复运行。避免同一数据目录同时执行多轮；采集锁会拒绝重叠写入。实际运行频率还取决于自动化工具、设备是否运行、时区及网络。

本卡不授权 Agent 创建或修改定时任务、通知渠道、系统 Cron 或第三方账户设置。
