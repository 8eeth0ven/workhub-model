# 代码与图检索

检索 AI 原生工程前沿，把公开项目更新、进阶研究资料和本地代码关系放到同一工作台，用证据判断哪些方法值得应用。

默认 Codex 明亮，紧凑工具栏、中英文和统一配色。默认先看“前沿更新”，也可切代码检索、关系图和提升资料。17 个进阶官方入口覆盖 Agent 工程、长任务上下文、工具与运行环境、评测、训练反馈、代码图谱、GraphRAG和时序记忆；不以基础语法教程作为默认内容。重复入口按规范化 URL 合并，资料入口不代表已安装相关工具。

## 开始使用

需要 Python 3.10+，只用标准库。可先在安装目录生成离线虚构演示：

```sh
python3 bin/build_data.py --demo
```

索引自己的项目，替换占位路径；只读取明确选定根目录内的 Python 文件，不执行其代码：

```sh
python3 bin/index_code.py --project /path/to/your-project
python3 bin/build_data.py
```

打开 `site/index.html`，或从模块仓库运行：

```sh
python3 manage.py connect coding-graph --installed ../my-coding-graph --workhub ../workhub
```

连接只登记站点。新版 Workhub 若采用手动入库，仍由用户选择加入工作空间。安装不运行索引，不创建自动化。

## 前沿更新与验证

```sh
python3 bin/collect_updates.py
python3 bin/build_data.py
```

从固定七个官方 GitHub 仓库各读取一页、最多六条 release，再按发布时间筛选近 90 天。它是有限采样，不承诺覆盖窗口内全部发布或严格最新六条；保留发布时间、采集时间、原始链接与预发布标签，首次未采集会明确显示。可选 `--proxy`，默认不读取环境代理、不需Key。它不是全网爬虫，也不把没有release说成项目没有进展。所有来源失败保留上次快照和原观察时间，来源状态另行保存。

前沿资料不是按新旧或星数排“最好”。每项附一个项目实验和反证问题，比较时保存任务、模型、环境、预算与验证口径。基础概念只在解释具体实现时按需补充。

## 查代码，也练习图

CLI 支持 `query`、`context`、`impact`、`trace`。在网页可搜索符号和资料、选中节点查看关系、查有向最短路径和逆向影响。默认只沿调用关系；所有关系的路径不等于执行链。具体参数见 [使用与边界](docs/guide.md)。

首版只解析 Python。索引是有界静态近似；动态调用、歧义、局部遮蔽和未支持构造可能未解析。图上没有边不代表运行时没有调用，静态匹配也不是已执行证明。文件哈希和索引时间用于核对来源；源码变化后须重新索引。

[GitNexus](https://github.com/abhigyanpatwari/GitNexus) 是参考项目，参考其“检索→符号上下文→影响→路径”的流程。本模块为独立 Python AST 实现，没有捆绑 GitNexus、其 MCP、语义向量检索、Cypher引擎或多语言解析器。官方仓库当前标注 PolyForm Noncommercial 1.0.0，使用其软件前阅读其许可证；本模块不复制其源码。

## 边做边学与隐私

每条提升资料附一个小练习和自检问题。可把 [学习提示词](prompts/code-learning.md) 交给自己选择的 CLI/API，要求按文件行号解释概念并指出未知；模块不会自动调用模型。理解状态由用户自己在 Workhub 学习卡中勾选，搜索或播放不是已学会。

实际代码索引、项目名、图数据与生成页面保留在本机，均不在源码包内。索引器有文件/字节/节点/边上限，跳过私有和运行目录、符号链接；达到边界或文件失败时显示覆盖告警。不要上传真实索引来代替源码。
