# 英语成片学习

把词表和日常句子铺成连续词片，滑着看、按需听，不做一词一关。

默认 Codex 明亮，支持中英文界面和 Workhub 配色。声音、语速、片大小、语言与配色放在可展开的“设置”，保存与播放限制收在折叠说明中。每片 8／16／32 条，全部词片纵向连续展示。单词和例句可以点播，也可整片连续播放、暂停、继续或停止。筛选、切换视图、页面隐藏时取消播放；播放不会自动标记学会，“已看过”由你亲自勾选。

初始材料为自编的 **48 个词、24 句日常表达、8 个生活场景**，不是不背单词或其他应用的会员内容。

## 启动

需要 Python 3.10+ 和现代浏览器，无模型 Key、无第三方 Python 包。在安装目录执行：

```sh
python3 bin/serve.py --port 8831
```

打开 `http://127.0.0.1:8831/`。服务只监听本机，导入和“已看过”保存到模块的 `data/library.json`。可用 `--data-dir` 选择自己的数据目录。请使用页面的“导出备份”；当前没有跨设备同步，手机上的词表需要先转移到运行服务的电脑。

接入 Workhub 时先保持服务运行，再从模块仓库执行：

```sh
python3 manage.py connect english-slices \
  --installed ../workhub-local/english-slices --workhub ../workhub \
  --site-url http://127.0.0.1:8831/
```

使用不同门户端口时，启动服务增加 `--parent-origin`，例如 `--parent-origin http://127.0.0.1:8797`。这里只登记已运行站点，不自动启动服务或创建定时任务。新版门户还需由用户在“接入项目”选择目录加入工作空间。

## 导入自己的材料

页面支持 CSV、TSV、JSON、TXT，单次最多 2 MiB、10000 条。常用中英文字段自动识别，详见 [导入说明](docs/import.md)。完全相同条目合并；同一单词的不同释义、例句或场景继续保留。

不背单词 [iOS 官方版本记录](https://apps.apple.com/cn/app/id698570469) 曾注明支持“导出 PDF”；具体入口与范围仍需在手机客户端核实。这里没有读取账号或会员接口，也没有内置 PDF/OCR 解析。取得自己的 PDF 后，先转为受支持的表格并核对文字，再导入。没有实际导出文件时，不能认为会员词表已经迁移。

## 声音与预览

播放使用浏览器 Web Speech API 和系统提供的英语声音。声音列表会随系统加载更新；缺少英语声音、不支持语音或播放失败时会提示。部分声音需要联网，不能保证每台设备离线可用。请检查系统英语语音和音量，浏览器也可能要求先点击播放。

仅看静态示例可运行：

```sh
python3 bin/build_data.py --demo
```

生成 `site/index.html`，无需服务即可浏览。**静态模式的导入和已看过状态只存在当前浏览器来源**，换端口、换浏览器或清理存储可能丢失，不等于已写入本机数据文件。使用本机服务模式获得文件持久保存。

## 发布边界

安装仅复制源码，不执行、不联网收集、不接触手机账号。公开包不包含个人词表、学习进度、运行网页、日志或测试文件。HTTP 服务拒绝外部 Host 和跨站写入，不对局域网提供访问。兼容入口不等于所有浏览器或系统声音均已实测。
