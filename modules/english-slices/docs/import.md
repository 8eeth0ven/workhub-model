# 导入词表与备份

只导入你自己选择的文件。不要把应用密码、授权令牌或完整账号导出放进词表。

CSV／TSV 表头可用 `word`／`单词`／`词汇`，`meaning`／`释义`／`中文`，`example`／`例句`，`translation`／`翻译`，`scene`／`场景`。无表头时按这五列顺序读取，缺少释义和例句允许留空。TXT 每行一个词，保留多词短语。CSV 使用引号保留逗号或多行例句。

```csv
word,meaning,example,translation,scene
bank,银行,I need to go to the bank.,我需要去银行。,办事
bank,河岸,We sat on the river bank.,我们坐在河岸边。,出游
```

两条 bank 的含义不同，分别保留。完全相同的词、释义、例句、翻译和场景合并。JSON 可为词条数组，或包含 `words` 和 `phrases` 的对象；`phrases` 的字段为 `text`、`translation`、`scene`。页面导出的备份同时保留用户手工勾选的 Seen 状态。

初始示例与个人导入都留在本机，不会上传到模型或词典服务。语音由浏览器／系统提供；部分系统声音可能联网，不是本模块提供的离线录音。

## 不背单词手机材料

[官方 iOS 商店页面](https://apps.apple.com/cn/app/id698570469) 的版本记录出现过“导出 PDF”，但不能据此推定所有词书、收藏句子都能批量导出，也不能确定你当前版本里的按钮位置。先使用客户端实际提供的导出或分享入口；没有文件时保留待迁移状态。

本模块不直接处理 PDF。文字型 PDF 可先由本机工具转成文本；扫描型 PDF 需要 OCR，再核对词义、换行和例句。最终整理为上面的 CSV／TSV／JSON／TXT。系统 `pdftotext` 等工具是否存在需要另行检查，本模块不会安装依赖或调用未确认的命令，也不会绕过会员限制。

## 数据位置

服务模式的数据文件在安装目录 `data/library.json`，或启动时选择的 `--data-dir`。保存采用原子替换，导入错误不覆盖原词表；已有数据损坏时会明确报错，不静默重置成示例。当前支持单个服务实例写同一数据目录，不要同时启动两个实例共用该目录。

静态模式只存浏览器来源。使用“导出备份”保存 JSON，再在同一模式或服务模式导入恢复；切换到另一台电脑时也需自行转移备份。播放、滑动或看完一片都不会替你勾选“已看过”。

服务用独占锁防止两个进程同时写同一目录。强制终止后若遗留 `.server.lock`，先确认没有服务正在使用该目录，再移除锁后重启。
